# High-Freq Sound Meter

スマートフォンや PC のマイクで、19 kHz / 21 kHz の高周波音のレベルをリアルタイムに表示するブラウザ用ツールです。

**▶ https://tntetsu.github.io/SPLmeter/**

インストール不要で、ブラウザで開くだけで使えます。

## 使い方

1. 上記 URL をブラウザで開きます。
2. 測定する周波数（**19kHz** / **21kHz**）を選びます。
3. **Start** を押し、マイクの使用を許可します。
4. 現在のレベル（Real-time）と最大値（Peak Value）が表示されます。

| ボタン | 動作 |
| --- | --- |
| 19kHz / 21kHz | 測定する周波数を切り替えます（ピーク値もリセットされます） |
| Start / Stop | 測定を開始・停止します。停止するとマイクも解放されます |
| Reset Peak | ピーク値をリセットします |
| 画面を180度回転 | 画面の上下を反転します。端末を逆さに持ち、マイクを音源に向けたまま表示を読むときに使います |

## 測定の仕組み

- Web Audio API の `AnalyserNode`（FFT サイズ 4096）でマイク入力の周波数スペクトルを求め、目標周波数に対応する FFT ビンとその前後 1 ビンのうち最大の値を表示します。
- 高周波のレベルが変わらないよう、ブラウザのエコー除去・ノイズ抑制・自動ゲイン調整はオフにしています。
- 音声データはブラウザ内だけで処理されます。録音やサーバーへの送信は行いません。

## 注意事項

- **表示値は相対値です。** 表示されるのはデジタルフルスケール基準の相対 dB（dBFS）で、校正された音圧レベル（dB SPL）ではありません。同じ端末での比較に使ってください。
- **端末によって結果が大きく変わります。** 多くのマイクは 19 kHz 以上で感度が大きく下がるため、端末ごとの値は直接比較できません。
- **21 kHz の測定には、サンプリング周波数 44.1 kHz 以上が必要です。** それより低い端末では正しく測定できません。
- **HTTPS か localhost で開く必要があります。** ブラウザの制限により、それ以外ではマイクを使えません。

## ローカルで動かす

ビルドは不要です。`index.html` を Web サーバーで配信してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

VS Code の拡張機能 Live Server（「Go Live」）でも動かせます。
